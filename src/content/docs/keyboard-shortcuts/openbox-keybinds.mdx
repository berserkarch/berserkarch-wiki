<Aside type="note">
  Key notation: **W** = Super (Windows key) · **A** = Alt · **C** = Ctrl · **S** = Shift
</Aside>

## Applications

| Shortcut | Action |
|----------|--------|
| `Alt + Return` | Open terminal (kitty) |
| `Alt + D` | Open rlaunch (app launcher) |
| `Alt + P` | Open plaunch |
| `Alt + S` | Open slaunch |
| `Super + E` | Open file manager |

## Window Management

| Shortcut | Action |
|----------|--------|
| `Super + Q` | Close window |
| `Super + F` | Toggle maximize |
| `Alt + Escape` | Lower window and unfocus |
| `Alt + Space` | Open window client menu |

## Window Switching

| Shortcut | Action |
|----------|--------|
| `Alt + Tab` | Cycle to next window |
| `Alt + Shift + Tab` | Cycle to previous window |
| `Ctrl + Alt + Tab` | Cycle windows (including panels & desktop) |
| `Super + Shift + Right` | Directional cycle windows (right) |
| `Super + Shift + Left` | Directional cycle windows (left) |
| `Super + Shift + Up` | Directional cycle windows (up) |
| `Super + Shift + Down` | Directional cycle windows (down) |

## Desktop Switching

| Shortcut | Action |
|----------|--------|
| `Ctrl + Alt + Left` | Go to desktop left |
| `Ctrl + Alt + Right` | Go to desktop right |
| `Ctrl + Alt + Up` | Go to desktop up |
| `Ctrl + Alt + Down` | Go to desktop down |
| `Super + 1–5` | Go to desktop 1–5 |
| `Super + Shift + H` | Toggle show desktop |

## Send Window to Desktop

| Shortcut | Action |
|----------|--------|
| `Alt + Shift + Left` | Send window to desktop left |
| `Alt + Shift + Right` | Send window to desktop right |
| `Alt + Shift + Up` | Send window to desktop up |
| `Alt + Shift + Down` | Send window to desktop down |

## Mouse Bindings

| Action | Effect |
|--------|--------|
| `Alt + Left click drag` | Move window |
| `Alt + Right click drag` | Resize window |
| `Alt + Middle click` | Lower window and unfocus |
| `Alt + Scroll Up` (on frame) | Go to previous desktop |
| `Alt + Scroll Down` (on frame) | Go to next desktop |
| `Left click drag` (titlebar) | Move window |
| `Double click` (titlebar) | Toggle maximize |
| `Scroll Up` (titlebar) | Shade (roll up) window |
| `Scroll Down` (titlebar) | Unshade (roll down) window |
| `Right click` (titlebar) | Open client menu |
| `Middle click` (titlebar/border) | Lower window |
| `Right click` (desktop) | Open root menu |
| `Middle click` (desktop) | Open window list menu |
